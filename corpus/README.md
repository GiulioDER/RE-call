# Demo Corpus

This directory is the bundled product demo corpus used by the README and examples. It is small on
purpose: five markdown files show the trust behavior without requiring private data or benchmark
downloads.

What it demonstrates:

| File | Purpose |
|---|---|
| `rate_limits_v1.md` | Stale policy memory. |
| `rate_limits_v2.md` | Current policy memory that supersedes v1. |
| `hypotheses.md` | Closed and open research-style memories. |
| `decisions.md` | Adopted product decisions. |
| `infra.md` | Ordinary supporting memory. |

Use it only for local demos and smoke tests. It is not an evaluation benchmark and does not support
quality claims.
