Install the current release

Two commands get you to the guided setup.

Python 3.11 or newer and Docker are the supported prerequisites. Docker runs the PostgreSQL database locally; the default embedding path keeps corpus text on your machine.

PowerShell, macOS or Linux 
python -m pip install "recall-rag[fastembed]"
recall quickstart

The quickstart is a disposable demonstration. Remove its database with recall quickstart --remove, then return to the full install for your own corpus.

For your own memory

Run setup after the demo.

PowerShell, macOS or Linux 
python -m pip install "recall-rag[fastembed]"
recall setup

The wizard applies the schema, asks for the embedder and retrieval options, indexes your corpus, offers calibration and configures the selected agent integration.
