Before you start

Download the pieces you actually need.

I checked the official download links on August 14, 2026. For a first RE-call install, the simplest stack is Python, Docker Desktop, and this repository.

Best beginner choice

Use Docker Desktop for PostgreSQL plus pgvector unless you already run PostgreSQL and already know how you want to install the `vector` extension.

Essentials

Required downloads and what each one is for

Tool Why you need it Best first choice Official link
Python 3.11+ Runs the RE-call CLI, setup wizard, and MCP server. Install the latest stable Python 3 release from python.org. python.org/downloads
Docker Desktop Gives you the easiest local PostgreSQL plus pgvector path used by the repo quickstart. Install Docker Desktop for your OS and start it before running `docker compose`. docker.com/products/docker-desktop
PostgreSQL RE-call stores its memory index in PostgreSQL. Use the Docker path first. Native PostgreSQL is optional if you already want a managed install. postgresql.org/download
pgvector Provides the vector extension PostgreSQL needs for embedding search. Use the repo Docker image, `pgvector/pgvector:pg18`, unless you are doing a native database install. github.com/pgvector/pgvector
Claude Code Optional, only needed if you want RE-call as a memory tool inside Claude. Install Claude Desktop or Claude Code after RE-call works locally. Claude Code overview

Platform notes

Windows and macOS choices

Windows

What I recommend

  • Python from python.org, not the Microsoft Store, so the install path is predictable.
  • Docker Desktop for Windows with WSL 2 support if Docker asks for it.
  • PowerShell for every command in this guide.

macOS

What I recommend

  • Python from python.org, usually the universal macOS installer.
  • Docker Desktop for Mac, using the Apple Silicon or Intel build that matches your machine.
  • Terminal for every command in this guide.
Why I do not start with native PostgreSQL

The repo quickstart already assumes a containerized pgvector image. That path removes most of the beginner failure points: extension install, service management, and server version mismatch.

Optional extras

What you may install later

Extra When to add it Install command
`[mcp]` When you want Claude Code or Claude Desktop to call RE-call tools. pip install -e ".[fastembed,mcp]"
`[rerank]` When you want higher retrieval quality and can pay the extra local latency. pip install -e ".[fastembed,rerank]"
Cloud embedders When your data is allowed to leave the machine and you want hosted embedding models. Follow the main README and environment docs.
