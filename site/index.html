What you are installing

A memory that would rather say nothing than guess.

RE-call stores notes, decisions, and project history, then searches them by meaning.

When nothing matches with enough confidence, it abstains instead of handing you the nearest note.

The middle question recall quickstart asks

Output
[ABSTAIN GAP] query='penguins on Mars?'
  reason: no confident match in this corpus
  evidence: rate-limits.md · confidence 0.30

A low-confidence match is shown as evidence, not presented as an answer.

How it works

Memory checked before it answers.

Lite binds calibration to its local corpus; PostgreSQL serves an immutable calibrated generation. Both evaluate trust before returning evidence. The diagrams below show the PostgreSQL generation path and link to its source.

The moving parts

Choose the store, keep the trust layer.

Lite is the local path for one project. PostgreSQL adds server operations when you need them.

PieceWhat it doesYou touch it
SQLite file or PostgreSQL database Stores your notes, embeddings, calibration, and fact ledger. Lite refreshes locally; PostgreSQL needs database operations.
The RE-call package Indexes markdown and decides whether a result is safe to use. Every query.
The MCP server Lets Claude Code, Codex, or another MCP client query the configured store. Optional.

Windows, macOS and Linux

Install Lite from source, or PostgreSQL from PyPI.

Lite is in the repository source; the published 0.14.0 wheel predates it. The install guide provides the source environment, project setup, refresh checks, software updates, and backup steps.

The current GitHub release does not include a standalone Windows installer. The release page explains the available package files and the supported install path.

Set up Lite

What you need

Lite needs Python, Git for the source install, and a local memo folder. PostgreSQL needs a compatible database; Docker can provide one. Both editions use the same trust layer.

The current release page links to PyPI and GitHub, and the full install guide walks through the setup.
