Why this site exists

The repo docs are accurate, but they assume you already know the moving parts.

RE-call stores memory in PostgreSQL, indexes it with pgvector, and layers trust, calibration, and Claude integration on top. For a first run, what matters most is the order of operations. This site gives that order.

The shortest successful path

Install Python and Docker Desktop, start the bundled pgvector container, install `recall-rag[fastembed]`, apply the schema, then run `python -m recall.cli setup`.
